# Sustainability Tracker: Codebase Briefing

The Sustainability Tracker is a full-stack application designed to help users track and reduce their environmental impact. It features a Django-based backend for data management and a modern React (Vite) frontend for an interactive user experience.

## Core Functionalities

-   **Daily Habit Logging**: Users can log activities in categories like Transport, Energy, Food, and Waste. The system calculates the CO2e impact in real-time.
-   **KPI Dashboard**: A central visualization of today's footprint, eco-scores, and consistency streaks.
-   **AI-Powered Insights**: Personalized recommendations and a 7-day action plan based on historical data.
-   **Reporting & Analytics**: Comprehensive reports with filtering options and the ability to export data as CSV or PDF.
-   **Community Engagement**: Global and friend leaderboards, plus featured community challenges.
-   **Company Management**: Automatic company profile creation for each user to aggregate data.

## Backend Architecture

-   **Framework**: Django with Django REST Framework (DRF) for the API.
-   **Database**: SQLite ([db.sqlite3](file:///c:/Users/maana/OneDrive/Desktop/Sustainability-traker/backend/db.sqlite3)) for local development.
-   **Core Models**:
    -   `User`: Standard Django user for auth.
    -   [Company](file:///C:/Users/maana/OneDrive/Desktop/Sustainability-traker/backend/core/models.py#4-19): Linked to a user, groups all sustainability data.
    -   [EmissionRecord](file:///C:/Users/maana/OneDrive/Desktop/Sustainability-traker/backend/core/models.py#21-32): The main data point (category, value, unit, and calculated `co2e_impact`).
    -   [UploadedFile](file:///C:/Users/maana/OneDrive/Desktop/Sustainability-traker/backend/core/models.py#33-41): Records of files uploaded for batch processing.
-   **Calculations**: Stored in [conversions.py](file:///C:/Users/maana/OneDrive/Desktop/Sustainability-traker/backend/core/conversions.py), using fixed factors (e.g., Electricity = 0.82 kg CO2e/kWh).
-   **Async Tasks**: Uses Celery (configured in [celery.py](file:///C:/Users/maana/OneDrive/Desktop/Sustainability-traker/backend/backend/celery.py)) to process uploaded files without blocking the API.
-   **Report Generation**: Powered by a custom reporting service that generates PDF buffers.
